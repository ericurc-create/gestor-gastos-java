# Gestor de gastos personales

Versión 0.4

## Descripción

Aplicación de consola desarrollada en Java que permite gestionar ingresos y gastos personales, calcular el saldo disponible y consultar un resumen del estado de la cuenta.

Proyecto desarrollado durante mi formación en Desarrollo de Aplicaciones Web, con el objetivo de aplicar progresivamente los conocimientos adquiridos en programación.

## Funcionalidades

- Menú interactivo de consola.
- Registro y acumulación de ingresos y gastos.
- Cálculo del saldo disponible.
- Clasificación del balance en positivo, negativo o equilibrado.
- Resumen de cuenta con formato monetario.
- Validación de importes negativos.
- Validación de las opciones del menú.
- Control de excepciones ante entradas incorrectas.
- Gestión de cantidades monetarias mediante BigDecimal.

## Conceptos de programación aplicados

- Variables y tipos de datos.
- Operadores aritméticos, relacionales y lógicos.
- Estructuras condicionales.
- Bucles while y do-while.
- Estructuras switch.
- Métodos, parámetros y valores de retorno.
- Ámbito de las variables.
- Variables booleanas de control.
- Tratamiento de excepciones mediante try-catch.
- Precisión monetaria mediante BigDecimal.
- Programación modular y reutilización de código.
