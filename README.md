# Gestor de gastos personales

## Descripción

Es una aplicación que funciona por consola, está desarrollada en Java y lo que hace es registrar los ingresos y gastos mensuales, y calcular el balánce económico.

## Funcionalidades

- Introducir ingresos mensuales.
- Introducir gastos mensuales.
- Validar que las cantidades no sean negativas.
- Calcular el saldo mensual.
- Mostrar si el balance es positivo, negativo o equilibrado.

## Tecnologías utilizadas

- Java
- Git
- GitHub
